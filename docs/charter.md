# Charter

## Purpose

Dotnet-Vue is a portfolio showcase for a modern full-stack web architecture:
a Quasar/Vue 3 server-side-rendered frontend and a .NET 8 backend API,
packaged for reproducible local use with containers.

## Audience

- Technical reviewers assessing .NET, Vue/TypeScript, SSR, containerization,
  and infrastructure-as-code familiarity.
- Contributors who need a clear local development starting point.

## Success measures

- A reviewer can understand the component boundaries and run the documented
  local workflow.
- The repository demonstrates secure defaults and maintainable frontend/backend
  separation.
- Delivery claims distinguish local validation from a production deployment.

## Ownership and cadence

The repository owner maintains priorities through GitHub Issues and the
personal portfolio Project. Update this document when the intended showcase
story, audience, or operating posture changes materially.
