# Scope and roadmap

## Current scope

- Quasar/Vue 3 SSR frontend with TypeScript, Tailwind, Pinia, and routing.
- .NET 8 API with health and authentication endpoints documented in the root
  README.
- Local development and containerized workflows using the repository's Docker
  assets.
- Kubernetes and Docker Swarm manifests retained as deployment learning
  artifacts.

## Explicitly out of scope

- Claiming an active production, cloud, Kubernetes, or Swarm deployment.
- Changing credentials, manifests, image registries, environments, or CI/CD as
  part of documentation work.
- Committing secrets or environment-specific values.

## Roadmap review points

1. Verify the local development and Docker instructions against the current
   dependency versions before presenting a live demo.
2. Decide whether Kubernetes or Swarm remains a meaningful portfolio story;
   validate and document one deliberately before treating it as supported.
3. Add focused feature or quality improvements only through separately scoped
   GitHub Issues.
